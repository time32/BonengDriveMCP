# 发布包边界

## 包含

- Python MCP服务和运行入口。
- C#桥接器源码、PowerShell构建脚本。
- 单元测试与只使用回环地址的厂商组件测试。
- 配置模板、依赖清单、部署说明。
- 可重复运行的GitHub源码打包脚本和逐文件SHA-256清单。

## 不包含

- 厂商exe、dll、许可证、Access数据库及反射/反编译输出。
- 通信协议Word文件、驱动固件bin、固件源码和导出工程。
- 现场MAC/IP选择、设备目录缓存、参数备份、波形、烧录任务和日志。
- 虚拟环境、编译产物、本机Codex配置、账号或凭据。
- 包含本机路径和现场标识的开发会话笔记。

`data/README.md` 是空数据目录的说明，不包含参考参数库。
包里的MAC字符串均为合成测试样例或由测试字序生成的示例；没有预选实机目标。

源码包需要在目标机器安装依赖和重新构建桥接器，不是包含厂商程序的免安装版。
保留整个源目录；本版不保证脱离scripts/目录的wheel安装方式可运行设备工具。

本版由项目所有者选择采用MIT许可证，Copyright (c) 2026 time32。仓库源码中的LICENSE不替代原厂软件及第三方依赖各自的许可。

## 复现打包

```powershell
.\.venv\Scripts\python.exe scripts\package_github.py
```

产物位于 `dist/`：源码ZIP、ZIP的SHA-256文件以及打包报告。
按明确文件清单取源码，不递归打包整个开发目录；文件类型、路径、凭据特征和MAC样例
都会在打包时检查。包内 `RELEASE_MANIFEST.json` 记录每个文件的路径、大小及哈希。

上传前解压ZIP，将包内顶层文件作为仓库内容提交。
若需要源码仓库，应提交这些文件，而不是仅上传一个ZIP。ZIP也可以作为Release附件。
